# Problem Card #1

### Problem
Debugging source code takes too much time because finding the root cause of errors is difficult.

**Actor**

- CS Students
- Software Developers

**Current Workflow**

```text
Write Code
    ↓
Run Program
    ↓
Read Error
    ↓
Search Google / Stack Overflow
    ↓
Modify Code
    ↓
Run Again
```

**Bottleneck**

Finding the root cause of the error.

**Impact**

- Long debugging time
- Lower productivity
- Delayed project completion

**Success Metric**

Reduce debugging time by 50%.

**Non-AI Alternative**

- Google Search
- Stack Overflow
- IDE Debugger

**AI Hypothesis**

AI analyzes the error, explains the cause, and recommends possible fixes.

**Quick Gut**

Workflow
